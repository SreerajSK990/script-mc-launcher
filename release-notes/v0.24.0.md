# Script Minecraft Launcher v0.24.0

Hello everyone, v0.24.0 is a behind-the-scenes release that makes updates more trustworthy and the launcher leaner.

---

## What is new in this release

- **Signed updates:** From this version on, every update is cryptographically signed, and the launcher refuses to install anything that does not carry a valid signature from this project. Updates download in the background as before, and installing one now restarts straight into the new version.
- **A leaner launcher:** The old Electron code that the native Rust launcher replaced has been removed for good, along with its dependencies, which makes the project smaller and simpler to build.

---

## Improvements & Fixes

- **Smooth transition:** Installs older than this version keep using the previous checksum-verified update path to reach v0.24.0, so nobody is left behind.
- **Simpler interface build:** The interface is now built with plain Vite, with no change to how the launcher looks or behaves.

---
