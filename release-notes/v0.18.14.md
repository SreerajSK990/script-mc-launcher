# Script Minecraft Launcher v0.18.14

Hey everyone, v0.18.14 is all about the launch pipeline. Fabric and Quilt work again on the versions that need mapping files, very old Minecraft versions get their sounds and textures back, and launches after the first one are noticeably faster.

---

## What is new in this release

- **Fabric and Quilt on 1.14 to 1.21:** The launcher now installs the intermediary mappings these loaders depend on, so modded instances on obfuscated Minecraft versions start correctly again.
- **Classic versions play properly:** Releases from before 1.6 now get their legacy sound and texture layout prepared automatically.
- **Live download progress:** Library, asset and Java runtime downloads now show real progress counts while an instance prepares to launch.
- **Faster repeat launches:** Once all assets for a version have been verified, later launches only check that each file is present at the right size instead of re-hashing thousands of files.

---

## Improvements & Fixes

- **Correct Java downloads from Settings:** The download buttons in Settings now install the Java version you clicked. They previously always installed Java 8. Java 25 for Minecraft 26.x is now listed too.
- **Reliable Java installs:** A Java runtime only counts as installed after every file has finished downloading, so an interrupted download is repaired on the next launch.
- **No library conflicts:** When a mod loader ships a newer copy of a library Minecraft already uses, only the newer copy goes on the classpath.
- **Per-version natives:** Native libraries are kept separately for each Minecraft version, so switching an instance's version no longer leaves stale files behind, and extraction problems are reported instead of ignored.
- **Smarter platform rules:** Library rules now respect CPU architecture, and launcher name, version, library folder and version type are passed to the game correctly.
- **Backup after playing:** The "back up worlds after playing" setting now runs automatically when the game closes normally.
