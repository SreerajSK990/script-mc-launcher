# Script Minecraft Launcher v0.18.7

Hi everyone, v0.18.7 fixes Microsoft authentication in the native desktop launcher, resolving window management collisions, query parameter decoding, and error diagnostics.

---

## What is new in this release

- **Robust Microsoft OAuth Flow:** The Microsoft login window now manages webview lifecycles dynamically, cleanly closing any prior login sessions and assigning unique session tokens to prevent window creation collisions.
- **Account Selection Prompt:** The Microsoft OAuth endpoint now enforces `prompt=select_account`, allowing users to select which Microsoft account to sign into or switch between accounts cleanly without being trapped by stale session cookies.
- **Comprehensive Error Diagnostics:** Detailed error reporting across Xbox Live, XSTS token authorization, and Minecraft profile verification. If an account is missing an Xbox profile, requires parental consent, or does not own Minecraft Java Edition, the launcher presents the exact reason directly in the account modal.

---

## Improvements & Fixes

- **Fixed "Microsoft login failed" Generic Masking:** Frontend error handling now captures string errors returned by the native backend, displaying the real failure reason instead of masking every issue under a generic fallback message.
- **Fixed Authorization Code Double URL-Encoding:** The redirect interceptor properly extracts and decodes query parameters using `url.query_pairs()`, preventing authentication codes containing special characters from being double-encoded and rejected by Microsoft's token endpoint.
- **Fixed Window Label Collisions:** Replaced the static window identifier with timestamped identifiers and pre-launch window destruction, allowing repeated login attempts without application restarts.
- **Enhanced Network Headers:** Standardized `Accept` and `Content-Type` JSON headers across all Xbox Live and Minecraft Services HTTP endpoints.
