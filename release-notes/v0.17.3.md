# Script Minecraft Launcher v0.17.3

Hi everyone, v0.17.3 resolves layout boundary regressions introduced in recent builds, restoring the pinned top search bar in the Mod Browser, fixing the expanding Live Logs terminal and auto-scroll, and preventing unintended API rate limits on catalog load.

## What is new in this release

- **Context-Aware Viewport Layouts:** The launcher now differentiates between fixed-viewport single-screen workspaces (Mod Browser, Live Logs, Skin Studio) and flowing document feeds (Dashboard, Instances, Settings). Viewport pages now retain strict 100% viewport ceilings with internal panel scrolling, while document pages retain full smooth scrolling with generous bottom padding.

## Improvements & Fixes

- **Pinned Mod Browser Header & Controls:** Fixed an issue where scrolling through mod, shader, or resource pack cards caused the entire page to move up, pushing the search bar, category filters, and instance selector off-screen. The top controls now remain firmly pinned at the top while only the card grid scrolls underneath.
- **Eliminated Rapid API Rate-Limiting:** Resolved a critical issue where an unconstrained catalog container caused the infinite-scroll sentinel element to be detected immediately on initial load. This previously triggered 8 consecutive page fetches (192 mods) within seconds without any user interaction, leading to Modrinth and CurseForge HTTP 429 rate limits. Catalog browsing now correctly loads a single page on initial query and only requests subsequent pages when you scroll near the bottom.
- **Fixed Live Logs Terminal Bounding & Auto-Scroll:** Fixed an issue where the terminal window expanded infinitely downwards into an endlessly growing page rather than scrolling internally. The terminal container is once again clamped to the visible viewport, and auto-scroll now reliably tracks incoming log streams to the newest line.
- **Skin Studio Viewport Alignment:** Refactored the Skin Studio root container to fill the workspace cleanly without calculating brittle hardcoded viewport offsets.

Validation includes full TypeScript checks across all processes, automated service and content tests, and production packaging.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.3.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.3.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.3.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
