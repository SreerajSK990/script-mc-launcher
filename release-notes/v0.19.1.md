# Script Minecraft Launcher v0.19.1

Hey everyone, v0.19.1 rounds out the mod manager with rollback snapshots and fixes the launcher's connections to Discord, Mojang skins and multiplayer servers. Screenshot galleries also load much faster.

---

## What is new in this release

- **Mod rollback snapshots:** Before mods are installed or updated, the launcher snapshots the instance's mod setup. Snapshots appear in the Backups tab next to world backups, and restoring one first saves your current setup so nothing is lost. Snapshots use hard links, so they are instant and take almost no extra disk space.
- **Cancel downloads:** Mod, resource pack and shader downloads now show live progress and can be cancelled from the transfer card.
- **Discord Rich Presence works again:** The launcher keeps one steady connection to Discord, completes the handshake properly and reconnects automatically if Discord starts later, so your status no longer disappears right after it is set.
- **Server status through DNS records:** Server pings now follow Minecraft SRV records, so servers whose address points to a different host or port show the correct status.

---

## Improvements & Fixes

- **Backup limits respected:** The "keep backups" setting now trims old world backups and mod snapshots automatically.
- **Skins and capes stay signed in:** Skin uploads and cape changes refresh your Microsoft session first, and a skin is only marked active once Mojang accepts it.
- **Fast screenshot gallery:** Screenshots load straight from disk instead of being encoded into the page, so large galleries open quickly.
- **Fuller mod pages:** CurseForge mods show their full description and screenshots, and Modrinth mods list their team members.
- **Safer cloning:** Cloning an instance or importing from another launcher now reports copy failures instead of finishing silently with missing files, and brings over scripts, map data and screenshots too.
