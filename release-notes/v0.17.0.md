# Script Minecraft Launcher v0.17.0

Hi everyone, v0.17.0 brings shader support and more control over changes to your instances. You can preview required mods before installing, recover an earlier mod setup, and restore world backups from inside the launcher.

## What is new in this release

- **Shader browsing and management:** Find shader packs on Modrinth or through the optional CurseForge integration, view project details and galleries, choose a version, or import a local shader ZIP. Each instance keeps its own shader packs. The launcher detects Iris, Oculus, and OptiFine and offers compatible Iris or Oculus installs where available. Choose the active pack inside Minecraft; Vanilla instances need a compatible mod loader first.
- **Dependency previews:** See the required mods before an installation begins. The launcher resolves dependency chains and pinned versions, reuses compatible installed files, and reports disabled requirements or declared conflicts. Optional dependencies stay optional, and managed requirements are checked again before launch. These checks rely on the metadata supplied by mod authors and providers.
- **Backup history and restoration:** The new Backups tab brings together mod recovery snapshots, world-save backups, and existing save ZIPs from version upgrades. Restores verify integrity and save the current state first. You can configure snapshot retention and enable world backups after a clean game exit. Backups are stored inside each instance, so deleting that instance also deletes its backups.
- **Crash guidance:** The Logs page offers explanations for recognizable memory, Java, missing-dependency, duplicate-mod, and OpenGL errors, with the log evidence and a suggested next step. Full logs remain available when a crash cannot be identified.

## Improvements & Fixes

- Mod updates preserve disabled states and report which updates succeeded or failed, with an option to retry failures. Recovery snapshots and file-level rollback protect the previous files when an installation fails or is cancelled.
- File downloads retry transient failures and time out stalled transfers. Managed mod and shader downloads display progress and transfer speed and can be cancelled.
- Instance operations are coordinated to prevent conflicting content changes during installation, restoration, or gameplay.
- Instance cloning now retains managed content metadata and custom Java settings.
- Instance details, the content browser, settings, and the skin studio load when opened. This reduces the initial renderer JavaScript bundle by about 60%; measured startup time remains around 1.3 seconds on the development machine.
- Instance tabs wrap to fit narrower windows, and shader version selection uses shader-engine compatibility metadata.

Validation includes TypeScript checks, the service suite, 21 focused content and recovery checks, and a production build. Live download checks covered Iris and Oculus with their required dependencies and BSL shaders. These checks validate installation and detection; Minecraft gameplay was not tested for this release.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.0.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.0.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.0.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
