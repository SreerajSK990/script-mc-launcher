# Script Minecraft Launcher v0.18.3

Hi everyone, v0.18.3 fixes the application desktop and window icon branding across our native Rust desktop runtime and installer packages.

## What is new in this release

- **Native App Icon Branding:** Fixed the Windows taskbar, desktop shortcut, and window title icons for the native Rust application, replacing the default placeholder with the official Script Minecraft Launcher logo.
- **Unified Multi-Platform Icons:** Generated high-resolution icons (ICO, ICNS, and multiple PNG resolutions) across the Tauri packaging pipeline.

## Improvements & Fixes

- **Installer Icon Embed:** The NSIS setup installer now embeds the official launcher icon.
- **Executable Resource Header:** Updated Windows PE resource headers to embed the multi-resolution `.ico` icon directly in the `.exe` binary.
- **Auto-Updater Continuity:** Synchronized `latest.yml` hash for seamless in-app auto-updating.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.18.3.exe:** Recommended Windows installer (~4.1 MB). Full NSIS setup powered by the native Rust desktop engine, creating Desktop and Start Menu shortcuts with the official logo.
- **Script.Minecraft.Launcher.0.18.3.exe:** Standalone portable executable (~17.4 MB). Pure native Rust release requiring no installation.
- **latest.yml:** Used automatically by the in-app updater.

All binaries target 64-bit Windows. If you encounter any bugs or questions, please open an issue on GitHub with your operational logs.
