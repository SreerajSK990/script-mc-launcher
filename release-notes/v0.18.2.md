# Script Minecraft Launcher v0.18.2

Hi everyone, v0.18.2 is a dedicated release completing our transition to the pure native Rust (Tauri v2) desktop engine across all distribution channels and in-app updaters.

## What is new in this release

- **Pure Rust Default Installer:** The standard Windows setup installer (`Script-Minecraft-Launcher-Setup-0.18.2.exe`) is now powered natively by our Rust (Tauri v2) NSIS package (~4.1 MB), providing an instant 96% reduction in installer download size.
- **Automated Rust Engine Migration:** In-app auto-updaters will automatically transition your existing installation to the native Rust desktop runtime upon restarting.
- **Zero Chromium Runtime Overhead:** Full removal of legacy Electron setup binaries from the release pipeline.

## Improvements & Fixes

- **Updater Verification:** Synchronized SHA-512 manifest verification in `latest.yml` with the native Rust NSIS package.
- **Engine Badge Confirmation:** The in-app TitleBar badge will switch to `RUST` and the Engine Architecture card under Settings will show active Tauri v2 status after updating.
- **Strict Quality Control:** Full passing of TypeScript typechecks and all 21 automated content integrity tests.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.18.2.exe:** Recommended Windows installer (~4.1 MB). Full NSIS setup powered by the native Rust desktop engine, creating Desktop and Start Menu shortcuts.
- **Script.Minecraft.Launcher.0.18.2.exe:** Standalone portable executable (~17.4 MB). Pure native Rust release requiring no installation.
- **latest.yml:** Used automatically by the in-app updater.

All binaries target 64-bit Windows. If you encounter any bugs or questions, please open an issue on GitHub with your operational logs.
