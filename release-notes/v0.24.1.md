# Script Minecraft Launcher v0.24.1

Hey everyone, v0.24.1 is a quick fix for importing instances from Prism Launcher.

---

## What is new in this release

- **Prism imports bring everything over again:** Newer versions of Prism Launcher keep each instance's game files in a folder called `minecraft`, while older ones used `.minecraft`. The launcher only looked for the old name, so imports from current Prism versions arrived without their mods, configs, worlds or options. It now finds either folder, the same way Prism does, and the import screen shows the correct mod count.

---

## Improvements & Fixes

- **No more empty imports:** If an instance being imported has no game files at all, the import now stops with a clear message instead of quietly creating an empty instance.

If you imported a Prism instance before this update and it came in empty, delete that copy and import it again.
