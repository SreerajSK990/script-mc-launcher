# Script Minecraft Launcher v0.17.5

Hi everyone, v0.17.5 brings layout polish and responsive refinements to the Dashboard's "Jump In" quick-join section, ensuring clean, legible cards across all window resolutions and preventing cramped text or button wrapping on smaller screens.

## What is new in this release

- **Responsive Jump In Grid Density:** Updated the quick-join card grid to dynamically switch between 2 generous columns (~340px each) on smaller or unmaximized desktop windows and 3 columns on wide or maximized monitors. This ensures that card contents always have ample horizontal room regardless of your screen size or launcher window dimensions.

## Improvements & Fixes

- **Compact World & Server Actions:** Simplified singleplayer world launch buttons from "Play World" to a clean, symmetrical "Play" (matching "Join" on server cards).
- **Button Line Wrap Guard:** Added global whitespace protection across the UI button system so action buttons never wrap into awkward multi-line stacks under container shrink pressure.
- **Shortened Gamemode Badges:** Streamlined singleplayer world badges from "Survival Mode" or "Creative Mode" to concise labels ("Survival", "Creative", "Adventure", "Spectator"), cutting badge width in half and preventing world titles from being prematurely truncated with ellipses.
- **Semantic Versioning Standards:** Formalized release bump guidelines in project documentation for future updates.

Validation includes full TypeScript checks across all processes, automated service and content tests, and production packaging.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.5.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.5.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.5.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
