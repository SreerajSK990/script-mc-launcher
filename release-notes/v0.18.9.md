# Script Minecraft Launcher v0.18.9

Hi everyone, v0.18.9 resolves an issue where Minecraft instances launched using a placeholder guest session instead of your authenticated Microsoft account, causing multiplayer server connections to fail with "Invalid session" and Realms authorization to fail.

---

## What is new in this release

- **Full Microsoft Account Session Wiring:** The game launcher now seamlessly queries your active stored account session when launching Minecraft. Authenticated Microsoft profiles provide their verified player name, UUID, and signed JWT access token, along with the `msa` user type.
- **Graceful Offline Account Fallback:** When launching with an offline profile or playing without an active account, the launcher continues to supply isolated offline credentials (`Player` or your chosen offline profile) without blocking game startup.

---

## Improvements & Fixes

- **Fixed "Invalid session (Try restarting your game and the launcher)":** Minecraft was previously supplied a placeholder offline token even when a verified Microsoft account was logged in, causing online multiplayer server handshakes and Realms to reject the session. The launch builder now passes valid authentication parameters and keeps your login status active.
- **Silent Token Refresh on Launch:** If your Microsoft authentication token is nearing expiration, the launcher automatically performs a silent token refresh before launching the game, ensuring uninterrupted online sessions.
- **Multiplayer and Realms Connectivity:** Online multiplayer servers, Realms, and Mojang services now correctly authenticate your account on join.
