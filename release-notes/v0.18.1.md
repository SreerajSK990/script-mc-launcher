# Script Minecraft Launcher v0.18.1

Hi everyone, v0.18.1 is an immediate follow-up release bringing auto-update pipeline alignment and real-time engine visibility across the launcher.

## What is new in this release

- **Active Engine Indicator Badge:** The launcher now displays a dedicated engine badge in the top TitleBar (`RUST` or `ELECTRON`) so you can instantly verify which desktop runtime is active.
- **Engine Architecture Dashboard:** Added an Engine Architecture card under Settings showing the active runtime engine, performance benefits, and isolation status.
- **Auto-Updater Alignment:** Fully synchronized updater manifests (`latest.yml`) allowing existing installed launchers to detect and apply updates seamlessly.
- **Dual Package Distribution:** Providing both the ultra-lightweight native Rust NSIS setup installer (~4.1 MB) and the standalone portable executable (~17.4 MB).

## Improvements & Fixes

- **Tauri Build Automation:** Configured native NSIS bundling for zero-dependency Windows setup packaging.
- **Disk Cache Hygiene:** Purged legacy pre-release artifacts and optimized local distribution staging.
- **Strict Verification:** Passed all TypeScript typechecking, automated test suites (21/21 content checks), and production packaging pipelines.

## Downloads Guide

- **Script-Minecraft-Launcher-Rust-Setup-0.18.1.exe:** Pure Native Rust NSIS setup installer (~4.1 MB). Lightweight installer creating Desktop and Start Menu shortcuts.
- **Script.Minecraft.Launcher.Rust.0.18.1.exe:** Pure Native Rust standalone portable executable (~17.4 MB). Instant startup and minimal RAM usage.
- **Script-Minecraft-Launcher-Setup-0.18.1.exe:** Standard Windows setup installer supporting background auto-updates.
- **Script.Minecraft.Launcher.0.18.1.exe:** Standard standalone portable executable.
- **Script-Minecraft-Launcher-Setup-0.18.1.exe.blockmap** and **latest.yml:** Used automatically by the in-app updater.

All binaries target 64-bit Windows. If you encounter any issues or have questions, please reach out via GitHub issues.
