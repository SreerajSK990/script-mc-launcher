# Script Minecraft Launcher v0.17.2

Hi everyone, v0.17.2 improves the shader browsing experience by introducing smooth infinite scrolling, eliminating the jarring scroll-to-top jump when paginating shader packs, adding quick scroll-to-top navigation, and ensuring installed shaders display accurate status badges.

## What is new in this release

- **Infinite Scrolling for Shaders:** The shader browser now loads subsequent pages automatically via IntersectionObserver as you scroll down the catalog, matching the smooth browsing experience of mods and resource packs.
- **Scroll-to-Top Navigation:** A floating quick-scroll button appears once you scroll down through the catalog, allowing you to return smoothly to the search bar and filter controls in a single click.
- **Memory Safety Pause:** To conserve system memory during prolonged browsing sessions, catalog auto-fetching automatically pauses after 8 pages and offers a "Continue Browsing" button to resume whenever you wish.

## Improvements & Fixes

- **Eliminated Pagination Scroll Jump:** Fixed an issue where clicking "Load More Shaders" caused the browser view to jump back to the very top. Existing shader cards now remain mounted uninterrupted in the DOM during background pagination fetches, with a dedicated non-blocking loading indicator at the bottom of the grid.
- **Accurate Installed Shader Badges:** Installed shaders now reliably display the green "Installed" status badge along with their installed version tag. Matching logic has been enhanced to recognize canonical project IDs, project slugs, clean name matching, and filename patterns for both online catalog downloads and manually imported ZIP archives (such as BSL, Complementary, MakeUp, and AstraLex).
- **Pinned Search Bar & Dedicated Viewport:** Resolved nested scroll containers in the Mod Browser so the search bar, loader status banner, and source selection pills remain firmly pinned at the top while only the shader cards container scrolls.
- **Metadata ID Preservation:** The shader installation pipeline now explicitly retains original catalog project IDs in shaders.json across Modrinth and CurseForge, ensuring seamless cross-referencing between installed packs and online version lists.

Validation includes TypeScript checks across the entire codebase, automated test suites, and production packaging.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.2.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.2.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.2.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
