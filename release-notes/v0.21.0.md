# Script Minecraft Launcher v0.21.0

Hello everyone, v0.21.0 adds two features many of you have asked for: sharing an instance as a modpack, and managing your worlds without digging through folders.

---

## What is new in this release

- **Export as a Modrinth modpack:** A new Export button on the instance page saves the instance as a `.mrpack` file. Mods, resource packs and shaders that are available on Modrinth are linked instead of copied, so packs stay small. Everything else, including your configs and game options, is bundled inside, and the exact loader version is pinned so the pack installs the same way everywhere. Exported packs import cleanly into this launcher and other launchers that support the Modrinth format.
- **World manager:** A new Worlds tab lists every singleplayer world with its icon, game mode, size and when you last played it. From there you can rename a world, back it up to a zip, open its folder, jump straight into it on Minecraft 1.20 and newer, or remove it.

---

## Improvements & Fixes

- **Safe world removal:** Removed worlds are moved to the instance's `deleted-worlds` folder rather than erased, so a misclick never costs you a world.
- **Careful renames:** Renaming a world only changes its display name inside `level.dat`, keeps a `level.dat_old` copy, and is blocked while the game is running.
