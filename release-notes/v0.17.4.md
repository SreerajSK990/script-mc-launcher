# Script Minecraft Launcher v0.17.4

Hi everyone, v0.17.4 enables live in-game shader and resource pack installation, imports, and management while Minecraft is actively running, removing false busy locks while keeping game JAR mods and destructive operations safely protected.

## What is new in this release

- **Hot-Swappable Shaders & Resource Packs During Active Gameplay:** Minecraft and shader engines (Iris, Oculus, OptiFine) natively support live reloading of shader packs and resource packs in-game without restarting the client. The launcher now allows you to browse, install, drag-and-drop import, and manage shader packs in `shaderpacks/` and texture packs in `resourcepacks/` without being blocked by instance busy errors while the game is running.

## Improvements & Fixes

- **Granular Instance Concurrency Protection:** Unwound broad instance reservation locks from atomic shader operations (`installShader`, `importShaders`, `deleteShader`). Mod JAR files (`mods/*.jar`), loader configuration changes, backups, and instance deletion remain strictly guarded to prevent process corruption and file locks, while content safe for in-game hot-reloading operates freely.
- **Atomic File Staging:** Shader installations and imports continue to write into isolated temporary files before atomic promotion, ensuring that active Minecraft sessions never encounter incomplete archives even if a download or import is interrupted.

Validation includes full TypeScript checks across all processes, automated service and content tests, and production packaging.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.4.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.4.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.4.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
