# Script Minecraft Launcher v0.18.5

Hi everyone, v0.18.5 brings a fully functional native in-app auto-updater to the Rust (Tauri v2) desktop engine. You no longer need to visit GitHub or manually download setup installers when a new version is released.

---

## What is new in this release

- **True In-App Background Auto-Updater:** The native Rust engine now automatically downloads release setup installers in the background when a new version is detected.
- **Real-Time Download Progress Tracking:** As new versions download, live transfer statistics (percentage progress, transferred MB vs total MB, and download speed in MB/s) stream directly to the Settings page and update notifications.
- **One-Click Restart to Apply:** Once an update finishes downloading, a green Restart to Apply button appears. Clicking it launches the installer as a clean detached process and safely exits the launcher so the update applies immediately without file conflicts.
- **Automatic Startup Update Detection:** The launcher automatically checks for updates 15 seconds after launch, alerting you through the update modal whenever an update is ready.

---

## Improvements & Fixes

- **Resolved Frozen Downloading Status:** Eliminated the issue where the updater status remained stuck on downloading due to missing background download workers in the Rust runtime.
- **Cached Update Recognition:** If an update setup file was already downloaded to your temporary folder, the launcher recognizes it instantly and offers the Restart to Apply action without re-downloading.

---
