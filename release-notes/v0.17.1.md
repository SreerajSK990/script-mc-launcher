# Script Minecraft Launcher v0.17.1

Hi everyone, v0.17.1 addresses an event-loop freeze that could cause Windows to report the launcher as "(Not Responding)" when opening shaders, and unifies shader browsing into our standard cyber-industrial interface.

## What is new in this release

- **First-Class Shader Pack Browser:** Shaders is now a native tab in the Mod Browser segmented control alongside Mods, Resource Packs, and Modpacks. It uses the launcher's standard title, subtitle, target instance selector, and Browse / Installed subtab pill toggle.
- **Modernized Shaders Interface:** The Shaders panel has been redesigned to match the launcher's dark theme: a styled search input with clear button, Modrinth and CurseForge provider toggle pills, action buttons for importing ZIPs and opening folders, and interactive shader cards with download counts, author attributions, and installation status.
- **Drag-and-Drop Shader Installation:** You can now drag and drop `.zip` shader packs directly onto the Mod Browser or the Shaders panel to immediately install them into your selected instance's `shaderpacks/` folder.
- **Streamlined Instance Detail Navigation:** Replaced raw button tabs in Instance Details with standard styled tab buttons (`Sun` for Shaders and `RotateCcw` for Backups), keeping instance navigation completely cohesive.

## Improvements & Fixes

- **Eliminated Main Thread Freeze:** Resolved the "(Not Responding)" lockup by replacing synchronous ZIP archive inspections of all installed JARs on Node.js's main thread with instant metadata lookups on mod IDs, names, and filenames already cached in `mods.json`. The environment check now completes in under 1 millisecond.
- **Shader Platform Identification:** Mod detail views now show supported platforms (`Iris, Oculus, OptiFine`) and fall back cleanly to all version releases when a shader project doesn't declare strict Minecraft version bounds.
- **Smoother Content Navigation:** Integrated the `onBrowseShaders` callback from instance configuration so jumping between instances and shader browsing stays fast and responsive.

Validation includes TypeScript checks, the automated services test suite, 21 content and recovery checks, live Iris and Oculus detection and shader download tests, and a production build.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.17.1.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates with a restart to install.
- **Script.Minecraft.Launcher.0.17.1.exe:** Standalone portable Windows executable. Runs without installation.
- **Script-Minecraft-Launcher-Setup-0.17.1.exe.blockmap** and **latest.yml:** Files used by the auto-updater. You do not need to download them manually.

Both executables target Windows x64. If you run into a problem, please open an issue with the relevant launcher logs and the Minecraft and mod-loader versions involved.
