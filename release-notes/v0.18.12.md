# Script Minecraft Launcher v0.18.12

Hi everyone, v0.18.12 focuses on keeping your data safe and making launches more dependable. It fixes a game freeze, protects saved accounts and server lists from being overwritten, and makes world restores much safer.

---

## What is new in this release

- **No more frozen games from unusual log output:** The launcher now reads the game's console output byte by byte, so a single line in an unexpected encoding can no longer stop log reading and freeze Minecraft.
- **One instance, one task at a time:** An instance can no longer be launched twice by double-clicking, and deleting, repairing, restoring backups, editing servers or installing mods is blocked while the game is running or another task is busy with it.
- **Migrated Microsoft accounts keep working:** Accounts saved by the older Electron build are decrypted and moved to the new encrypted storage automatically.
- **Safer world restores:** Restoring a backup now unpacks into a clean folder and keeps your current worlds as `saves.before-restore-<date>` instead of mixing old and new files together.

---

## Improvements & Fixes

- **Saved accounts are never wiped:** If the account file ever becomes unreadable, it is set aside with a timestamp instead of being replaced by an empty list.
- **Clear session warnings:** If a Microsoft session cannot be refreshed, the log now says so instead of silently launching with an expired token.
- **Server lists keep your settings:** Adding or removing a server keeps each entry's resource pack preference and other fields, keeps a `servers.dat_old` copy, and writes the file safely.
- **Custom Java paths can be cleared:** Removing a custom Java path or switching loaders now actually resets the saved values.
- **Accurate game status:** Stopping the game reports "Game stopped" instead of a crash, logs no longer appear twice, and older instance files load even if some fields are missing.
- **Java fallback:** If the managed Java runtime cannot be prepared, the launcher logs why and falls back to the Java installed on your system.
