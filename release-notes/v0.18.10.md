# Script Minecraft Launcher v0.18.10

Hello everyone, v0.18.10 addresses two critical stability issues reported with account authentication and game launch status monitoring: Microsoft OAuth login window errors and launch console event delivery.

## What is new in this release

- **Resilient Microsoft OAuth Authentication:** Fixed an issue where the login window closing could trigger connection aborted errors during the OAuth token exchange. Replaced abrupt window destruction with graceful hiding and cleanup, added a multi-tenant token exchange fallback supporting both consumers and common endpoints, and configured connection timeouts.
- **Dual-Channel Launch Progress & Log Streaming:** Progress updates and live console logs now emit directly to the main window as well as the application dispatcher, guaranteeing real-time status display and console output during launch without requiring a launcher restart.
- **Race-Free Event Listener Bridge:** Implemented an active subscription guard across all Tauri bridge listeners (launch status, live logs, modpack imports, updater status, and transfer events). This prevents zombie listener subscriptions and ensures event callbacks are cleanly wired on rapid UI navigation.

## Improvements & Fixes

- **Clear Network Error Traversal:** If Microsoft OAuth or Xbox Live token requests experience connectivity failures, the launcher now reports the underlying transport error instead of a generic failure message.
- **Safe Webview2 Teardown:** Secondary login windows are hidden immediately upon receiving the authorization code, and closed safely only after the complete authentication sequence finishes.
- **Version Metadata Synchronization:** Synchronized launcher version flags to 0.18.10 across Rust core and client configurations.
