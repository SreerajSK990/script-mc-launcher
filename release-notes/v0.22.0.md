# Script Minecraft Launcher v0.22.0

Hey everyone, v0.22.0 gives you more control over how each instance starts and catches common mod mistakes before they turn into a crash.

---

## What is new in this release

- **Per-instance launch options:** The Configuration tab now has a Launch Options section. Set a custom window size, start in fullscreen, and add a command to run before Minecraft starts or after it closes, for example to sync a world folder or start a voice chat tool. Commands run inside the instance folder, their output shows up in the Logs page, and a failing pre-launch command stops the launch so nothing starts in a broken state.
- **Duplicate and conflict warnings:** Before the game starts, the launcher now warns when two copies of the same mod are installed, or when renderer mods that cannot work together are present, such as OptiFine with Sodium, or Sodium with Embeddium or Rubidium.

---

## Improvements & Fixes

- **No slowdown from the checks:** Mod identities are cached, so the conflict check takes milliseconds after the first launch and runs alongside the normal file verification.
- **Clearer names for automatic installs:** Mods pulled in automatically as dependencies now show their real name instead of a long version title.
