# Script Minecraft Launcher v0.18.13

Hello again, v0.18.13 brings back several everyday features that went missing when the launcher moved to its native Rust runtime, and makes the window stay responsive during long tasks.

---

## What is new in this release

- **File pickers work again:** Choosing a modpack file, picking a launcher folder to import from, browsing for a Java executable, adding custom fonts and importing shader packs now open proper Windows file and folder dialogs.
- **Drag and drop is back:** Dropping mod jars, resource packs and shader packs onto the Mods tab, the Mod Browser or the Shaders panel installs them again, into whichever area you drop them on.
- **One launcher window:** Starting the launcher while it is already open now brings the existing window to the front instead of opening a second copy.

---

## Improvements & Fixes

- **No more frozen window during long tasks:** Importing from other launchers, scanning for instances, cloning instances, backing up and restoring worlds, deleting instances and inspecting modpacks now run in the background, so the window stays responsive and progress updates keep flowing.
- **Real error messages:** When something fails, the launcher now shows the actual reason (for example why a launch was blocked) instead of a generic "Launch failed".
