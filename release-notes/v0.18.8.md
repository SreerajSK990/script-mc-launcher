# Script Minecraft Launcher v0.18.8

Hi everyone, v0.18.8 fixes a Minecraft launch crash caused by conflicting quick-play arguments and eliminates the black console terminal window that flashed during game boot on Windows.

---

## What is new in this release

- **Feature Rule Isolation in Minecraft Arguments:** Mojang's modern game argument manifests include feature rules (such as demo mode, custom resolution, and quick-play flags). The launcher now properly isolates launcher-controlled features so unrequested flags are never accidentally pushed to the game process.
- **Silent Background Java Execution:** Configured Windows process flags (`CREATE_NO_WINDOW`) across the Java spawner and process supervision utilities so Minecraft launches completely silently without opening an extraneous Command Prompt or terminal window.

---

## Improvements & Fixes

- **Fixed "Only one quick play option can be specified" Crash:** Resolved the `IllegalArgumentException` thrown by Minecraft's `Main.getQuickPlayVariant` on startup. The launcher now passes only the explicitly requested target (or clean vanilla arguments if launching normally), eliminating duplicate `--quickPlaySingleplayer`, `--quickPlayMultiplayer`, and `--quickPlayRealms` options.
- **Suppressed Terminal Flash on Tool Execution:** Added `CREATE_NO_WINDOW` flags to `where` executable lookups and `taskkill` commands on Windows to prevent console flashing during system scans or instance stops.
- **Clean Quick-Play Version Handling:** Modern Minecraft (1.20+) receives `--quickPlayMultiplayer` / `--quickPlaySingleplayer`, while legacy releases receive classic `--server` / `--port` parameters.
