# Script Minecraft Launcher v0.19.0

Hi everyone, v0.19.0 brings the mod manager back to full strength. Installing a mod now brings its requirements along, update checks recognize every mod in your folder, and modpack imports handle CurseForge packs properly.

---

## What is new in this release

- **Automatic dependency installs:** Installing a mod from Modrinth or CurseForge now installs the mods it requires first, reuses copies you already have, and stops with a clear message if something is incompatible, disabled, or needs a manual download.
- **Update checks that know every mod:** Updates are found by matching each mod file's checksum against Modrinth, using the instance's current Minecraft version and loader. Mods you dropped in by hand or brought over from another launcher are now included, and updating everything shows live progress.
- **Real mod names for manual mods:** Mods added by drag and drop, by cloning or by hand now show their proper name and version, read from the mod itself instead of the file name.
- **Launch-time mod checks:** Before the game starts, the log now warns about missing or conflicting mod requirements.

---

## Improvements & Fixes

- **Better CurseForge modpacks:** Resource packs and shader packs inside CurseForge modpacks go to the right folders instead of `mods/`, files that authors only allow as manual downloads are listed when the import finishes, and lookup failures now stop the import with an error instead of silently leaving mods out.
- **Clean failed imports:** If a modpack import fails partway through, the half-created instance is removed automatically.
- **Correct override order:** Client-specific overrides in Modrinth packs now always win over shared overrides.
- **Richer CurseForge metadata:** CurseForge files keep their loader tags, required and incompatible dependencies, and a link to the file page.
