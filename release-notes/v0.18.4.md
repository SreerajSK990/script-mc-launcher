# Script Minecraft Launcher v0.18.4

Hello everyone, v0.18.4 resolves two key visual and networking issues: the white flashing that could occur when scrolling rapidly in full screen mode, and the initial offline status displayed for servers when starting the application.

---

## What is new in this release

- **Native Dark Window Composition:** Configured the native OS window and DirectComposition swapchain with a dark theme and matching background color (#0A0D14). Even before the webview paints or when rapid scrolling reaches viewport limits, the background remains consistently dark with zero white flashing.
- **Elastic Scroll Bounce Prevention:** Enforced strict overscroll behavior across HTML, body, and UI view containers to eliminate rubber-banding and white background exposure on fast trackpad and mouse-wheel scrolling.
- **Multi-Packet TCP Server Ping Accumulator:** Replaced the single-read TCP buffer with a streaming chunk accumulator in the native Rust networking layer. Large server response payloads containing descriptions, player counts, and base64 favicons are now fully assembled across TCP segments instead of being dropped due to MTU boundaries.
- **Automatic Ping Retry and Startup Sync:** Added a 250ms fallback retry for transient connection drops alongside a brief startup delay on the dashboard to ensure network adapters and DNS resolvers are ready before pinging.

---

## Improvements & Fixes

- **Server Status Reliability:** Minecraft servers with high-resolution custom server icons and formatted MOTDs (such as Hypixel or custom community networks) now show their online status, player counts, and latency immediately upon application launch.
- **Viewport Stability:** Full screen viewports now maintain uninterrupted dark styling during aggressive vertical scrolling across instance lists, mod browsers, and server dashboards.
- **Pure Native Rust Distribution:** Packaged with the latest native Rust engine and official branding icons in both standard installer and standalone portable formats.
