# Script Minecraft Launcher v0.23.0

Hi everyone, v0.23.0 makes signing in more flexible, adds datapacks to the world manager, and smooths out importing from CurseForge and the Modrinth App.

---

## What is new in this release

- **Sign in with a code:** The accounts dialog has a new "Sign in with a code instead" option. The launcher shows a short code, you enter it at microsoft.com/link in any browser, even on your phone, and the launcher finishes signing in by itself. Handy if the built-in login window ever gives you trouble.
- **Datapacks per world:** Each world in the Worlds tab now has a Datapacks section. See what is installed, remove packs, or search Modrinth for datapacks that match the instance's Minecraft version and install them with one click.
- **Finish CurseForge packs that need manual downloads:** Some CurseForge authors do not allow launchers to download their files. Those files are now listed on the instance's Mods tab with a link to each page. Download them as usual and the launcher picks them up from your Downloads folder, checks them, and puts them in the right place.
- **Better Modrinth App imports:** Profiles from the newer Modrinth App now import with their real name, Minecraft version, mod loader and loader version.

---

## Improvements & Fixes

- **Shared sign-in path:** Browser sign-in, code sign-in and session refresh now use the same Xbox Live and Minecraft sign-in steps, and each account remembers how it signed in so refreshes use the right service.
- **Safe reads:** The Modrinth App's database is opened read-only, so importing never changes anything in the other launcher.
