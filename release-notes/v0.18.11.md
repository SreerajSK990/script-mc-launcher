# Script Minecraft Launcher v0.18.11

Hey everyone, v0.18.11 is a security-focused update. It hardens how the launcher handles modpacks, mod descriptions, saved accounts and its own updates. Nothing changes in how you use the launcher, but every one of these fixes closes a real gap, so updating is strongly recommended.

---

## What is new in this release

- **Safer modpack imports:** Every file inside a modpack archive and every path listed in a Modrinth or CurseForge manifest is now checked before it is written. A malicious pack can no longer place files outside its own instance folder.
- **Encrypted account tokens:** Microsoft sign-in tokens are now encrypted with Windows' per-user data protection instead of being stored as plain text. Existing accounts are re-encrypted automatically the first time the launcher starts, and you stay signed in.
- **Verified updates:** The in-app updater now checks the installer's SHA-512 checksum against the release manifest before it will run it, and it only ever offers versions newer than the one you have.
- **Log4Shell protection for older versions:** Minecraft 1.7 through 1.18 now launch with Mojang's hardened logging configuration, while the Logs page keeps showing normal readable text.

---

## Improvements & Fixes

- **Sanitized mod descriptions:** Mod pages from Modrinth and CurseForge are cleaned before display, and the launcher window now runs with a strict content security policy.
- **Stricter internal checks:** Instance IDs, file names and backup names coming from the interface are validated before they touch the disk, links only open as web pages, and folders can only be opened inside the launcher data directory.
- **More reliable downloads:** Libraries, assets, Java runtimes, mods and modpack files now share one downloader that retries temporary network failures, verifies checksums while downloading, and never leaves half-written files behind.
