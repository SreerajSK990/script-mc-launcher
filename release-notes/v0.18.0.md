# Script Minecraft Launcher v0.18.0

Hi everyone, v0.18.0 is a major milestone release for Script Minecraft Launcher. In this update, we have introduced a high-performance Rust (Tauri v2) desktop backend engine, native Modrinth and CurseForge modpack importing, deep external launcher cloning, full shader management, and integrated recovery tools, all while preserving the modern React 19 interface.

## What is new in this release

- **High-Performance Rust Desktop Engine:** The entire launcher backend is now powered by native Rust (Tauri v2) alongside our dual-engine architecture. Enjoy faster startup times, near-instant instance queries, and a minimal memory footprint.
- **Native Modpack Importer:** Direct support for importing `.mrpack` (Modrinth) and `.zip` (CurseForge) archives. The engine handles recursive override extraction, mod catalog synchronization, and concurrent multi-threaded downloads with SHA-1 and SHA-512 verification.
- **Remote Modpack Installation:** Download and install complete modpacks directly from the Mod Browser with real-time progress reporting across extraction, dependency resolution, and asset downloading stages.
- **External Launcher Deep Cloner:** Automatically detect instances from Prism Launcher, MultiMC, Modrinth App, CurseForge App, and the Official Vanilla Launcher. Clone any instance with full isolation into its own sandboxed folder with configs, mods, and world saves preserved.
- **Shader Pack Management:** Browse, install, import, and delete shader packs directly from the instance dashboard. Automatic shader mod environment detection checks for Iris, Oculus, or OptiFine compatibility.
- **World Recovery & Saves Backup:** Create on-demand zip snapshots of your singleplayer worlds and restore previous backups safely with retention policy controls.
- **Native Discord Rich Presence:** Lightweight Discord IPC integration over OS pipes displays your active instance, Minecraft version, mod loader, and server activity.

## Improvements & Fixes

- **Dependency Planner:** Pre-installation dependency solver validates version compatibility, flags conflicts, and reuses matching local mod files before mutation.
- **Atomic Operations:** All configuration and metadata persistence utilizes atomic file writing to prevent data corruption during unexpected system restarts.
- **Comprehensive Quality Checks:** Full validation across TypeScript typechecking, automated unit and integration tests (21/21 passed), and native production packaging.

## Downloads Guide

- **Script-Minecraft-Launcher-Setup-0.18.0.exe:** Recommended Windows installer. Creates Desktop and Start Menu shortcuts and supports background auto-updates.
- **Script.Minecraft.Launcher.0.18.0.exe:** Standalone portable Windows executable that runs without installation.
- **Script.Minecraft.Launcher.Rust.0.18.0.exe:** Standalone native Rust binary for users wanting an ultra-lightweight (~16MB) executable.
- **Script-Minecraft-Launcher-Setup-0.18.0.exe.blockmap** and **latest.yml:** Used automatically by the updater.

All binaries target 64-bit Windows. If you encounter any bugs or have feature suggestions, please open an issue on GitHub with your operational logs.
