# Script Minecraft Launcher v0.20.0

Hi everyone, v0.20.0 starts a new round of features focused on making crashes easier to understand and the launcher more pleasant to come back to.

---

## What is new in this release

- **Crash reports in the console:** When Minecraft crashes, the launcher now finds the crash report it just wrote (and the Java crash log, if the JVM itself failed) and shows the important part right in the Logs page. The crash explanation at the top of the page now uses that report, so it can name the real cause instead of guessing from the console alone.
- **Saved session logs:** Every play session's full console output is saved to the instance's `launcher-logs` folder, keeping the latest ten. A new "Log Folder" button on the Logs page takes you straight there.
- **Pick up where you left off:** If you close or restart the launcher while Minecraft is still open, it now recognizes the running game the next time it starts. The instance shows as running, the Stop button works, and your playtime is still recorded when you quit.
- **Remembered window layout:** The launcher reopens at the size and position you left it, including maximized.

---

## Improvements & Fixes

- **Safer process matching:** A game is only re-adopted after confirming it is a Java process started at the recorded time, so an unrelated program that happens to reuse the same process ID is never mistaken for Minecraft.
